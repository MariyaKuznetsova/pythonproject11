# Проект приложение Рассылок

## Описание:

Проект приложение Рассылок

## Установка:

1. Клонируйте репозиторий:
```
git@github.com:MariyaKuznetsova/pythonproject11.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. В приложении рассылок, вы можете создать рассылку, посмотреть, удалить, редактировать.
2. В приложении рассылок, вы можете добавить клиента, посмотреть, удалить, редактировать.
3. В приложении рассылок, вы можете добавить сообщения, посмотреть, удалить, редактировать.
4. В приложении рассылок, вы можете отследить каждую рассылку и посмотреть статистику по всем рассылкам.
